# Vehicle Scheduling

A simple scheduling service for managing vehicle allocations.

## Setup

```bash
npm install
npm start
```

## What's Inside

- `src/index.js` - Main entry point
- `src/config/config.js` - Configuration
- `src/middleware/logger.js` - Logging middleware
- `src/service/schedulingService.js` - Core scheduling logic

## Running

```bash
node src/index.js
```

Check `.env` for configuration.
